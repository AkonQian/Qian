# MOTO GPS 0.3.2（7）：GitHub 云端打包说明

这是供你上传到自己 GitHub 仓库的 iPhone 源码包，包含电子吧唧功能和自动构建流程。不是 IPA，也不会给圆屏烧录。

## 本次功能

- 圆屏新增第 5 页“电子吧唧”。手机选择图片或 GIF，中心裁切成方形，通过蓝牙发送。
- 圆屏有 4 个保存位，支持替换、删除和选择；第 5 页短按 BOOT 键切换下一张，屏幕轻点不切图，左右滑仍用于切换分页。PWR 保留电源功能。重启后保留图片和选择。
- 静态图片转为 466 × 466 JPEG；GIF 最长 15 秒、最高 10 帧/秒，按大小自动选择 466、320 或 240 像素。每个保存位最多 512 KiB。原文件最多 20 MiB。
- 配套圆屏固件的音乐页通过标准蓝牙媒体按键发送播放/暂停、上一首、下一首；圆屏不播放声音。先在 iPhone 的汽水音乐中开始播放，再用圆屏控制。汽水音乐兼容性仍需真机验证。

电子吧唧需要新版 App 和配套圆屏固件同时具备；旧固件仍可连接导航，但不会出现可发送的相册连接。圆屏已于 2026-10-15 烧录本次固件，修复 BOOT 任务栈不足后已通过初步启动观察。新版 App 尚待云端编译和安装。

## 上传到自己的 GitHub 仓库

1. 在自己的 GitHub 账号下新建一个仓库，例如 `moto-gps-personal`。可以选择私有仓库。
2. 解压源码包。上传的是解压后的内容，不是把 ZIP 当成一个文件上传。仓库根目录应直接看到 `.github`、`platforms`、`shared`、`scripts` 和 `README.md`；不要再多套一层文件夹。
3. 文件较多时可用 GitHub Desktop 添加整个解压文件夹并发布到自己的仓库。保留 `.github/workflows/ios-sideload.yml`，不要漏掉点开头的目录。
4. 打开仓库的 **Actions**。若提示启用工作流，先启用。
5. 选择 **iOS sideload build → Run workflow → Run workflow**。首次上传也可能自动触发一次构建。
6. 等待构建成功，进入该次运行，在 **Artifacts** 下载 **MOTO-GPS-unsigned-IPA**。
7. 解压得到 `MOTO-GPS-0.3.2-7-unsigned.ipa` 和 `SHA256SUMS.txt`。使用此前安装 MOTO GPS 的签名工具和自己的 Apple 账号重新签名安装。未签名 IPA 不能直接在手机点开安装。

构建流程在 GitHub 的 macOS 运行器上生成 Xcode 工程，运行 App 单元测试及网关设置界面测试，再生成未签名 arm64 IPA。云端构建不需要上传 Apple 密码、签名证书、高德 Key 或 Cloudflare Token。

如果运行失败，先打开第一个失败步骤的日志。失败时没有经过验证的新版 IPA；不要把旧版 Release 下载误认为本次版本。

## 安装后测试

1. 打开 App，检查已有导航网关设置；如需重新填写，使用自己的网关根地址，例如 `https://nav.akonqian.cn/`，不附加 `/healthz`。
2. 仍使用原来的搜索和导航，确认正常后再测试新增功能。
3. 主界面点击“电子吧唧”，选择图片，选择保存位，发送；GIF 在手机只预览首帧，圆屏循环播放。
4. 圆屏左右滑到第 5 页，短按 BOOT 键并松开后切图；长按不连续翻图，其他页不响应切图。再验证重启保存、替换、删除和传输中断后重新发送。开机时不要一直按着 BOOT，以免进入下载模式。
5. 音乐页测试汽水音乐的三个控制按钮；系统若缓存了旧蓝牙服务，可能需要在 iPhone 设置里忽略旧配对后重新配对。

## 包的范围

这是 iOS 云端构建所需源码的精简副本，保留项目相对路径、共享协议和离线地图资源；不是完整固件或网关开发仓库。没有包含高德 Key、Cloudflare 凭据、Apple 证书、配对文件、原设备备份或现成 IPA。

圆屏源代码继续保存在本机原工程 `E:\Codex\moto-gps-waveshare`。本次固件及烧录记录单独保存在 `E:\Codex\moto-gps-install\firmware-media-badge-dev`，不覆盖原固件备份。
